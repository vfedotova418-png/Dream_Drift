# 💭 Dream Drift

## 📝 Описание

Dream Drift — это атмосферное Flutter-приложение, создающее успокаивающую визуальную среду на стыке океанских глубин и космического пространства. Погрузитесь в медитативный дрифт светящихся медуз и мерцающих звёзд под музыку \[dream] Сильвии Плат.

## 🔧 Возможности

| Функция             | Описание                                                                                   |
| ------------------- | ------------------------------------------------------------------------------------------ |
| Анимированная сцена | Непрерывная анимация медуз и звёзд, нарисованная с помощью CustomPainter                   |
| Фоновая музыка      | Воспроизведение музыкального трека с возможностью отключения звука и регулировки громкости |
| Цветовые темы       | Три визуальные темы: Ocean Space, Sunset Deep и Aurora Forest                              |
| Сохранение настроек | Выбранная тема, громкость и состояние звука сохраняются между сессиями                     |
| Навигация           | Три экрана: заставка с анимацией появления, главное меню и основная сцена                  |
| Панель настроек     | Bottom sheet с ползунком громкости и переключателем цветовых тем                           |

## 🚀 Как запустить

1. Клонируйте репозиторий

```bash
git clone https://github.com/vfedotova418-png/Subnautica_Interactive_Archive.git
cd dream_drift
```

2. Установите зависимости

```bash
flutter pub get
```

3. Добавьте фоновый трек

Поместите файл dream.mp3 в папку assets/audio/. Убедитесь, что файл присутствует и путь указан в pubspec.yaml.

4. Запустите приложение

```bash
flutter run -d windows
```

```
├── assets/
│   └── audio/

├── pubspec.yaml
└── README.md
```
